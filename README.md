# Bmax Social Platform

Bmax is a next-generation social platform centered around **Social + Create + Play + Collaborate**.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Backend/Database**: Supabase

## Key Features
- **Multiple Feeds**: For You, Following, Trending, Learning, Projects, Local
- **Reputation Scores**: Replaces purely follower-based status indicators
- **Remix Engine**: Chain content together via remixes and direct responses
- **Hyperlocal Discovery**: Discover projects, people, and discussions in your city
- **Direct Messaging**: Unlocked based on mutual follow status with persistent history
